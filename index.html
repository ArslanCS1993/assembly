Bit bar legend

  • ■ Green bits = value occupies this bit (RAX always green)
  • ■ Cyan bits = active/changed this cycle
  • ■ Amber bit-32 = 32-bit width marker (shows where 32-bit sub-register ends)
  • ■ Dark bits = zero / unused

Example: mov eax, 0x1234 → bits 0–15 green, bit-32 amber, bits 16–63 dark.
