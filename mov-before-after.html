Visual Language — MOV with Before/After State

Instruction Syntax (left-facing arrow = data flow)

mov
mov rax ← rbx

State Changes (Before → After)

Visual Language Rules

Arrow Direction

mov dst, src → dst ← src
Data flows right to left (source → destination)

Before/After Panels

Each affected operand gets a card:
• Green border = changed
• Gray border = unchanged
• Shows hex + binary + bit-width

Memory Representation

Memory shown as address + 8-byte value
[0x1000] = 0x0000000000000042
Bit bar shows occupied width
